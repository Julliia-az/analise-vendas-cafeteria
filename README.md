# ☕ Análise de Dados — Vendas de uma Cafeteria

Meu primeiro projeto de estudo em Ciência de Dados! 📊

Utilizei o Excel para analisar os dados de vendas de uma cafeteria, explorar indicadores e descobrir informações relevantes sobre o negócio.

## 🔎 Principais insights

- **Faturamento total:** R$ 4.616,50
- **Produto mais vendido:** Pão de queijo
- **Categoria com maior faturamento:** Bebidas
- **Maior lucro estimado:** Café coado
- **Forma de pagamento mais utilizada:** Pix
- **Variação mensal:** queda de 51,85% entre janeiro e fevereiro na métrica analisada

## 🛠️ Ferramentas

- Microsoft Excel
- Funções: SOMA, MÉDIA, SOMASE, SOMASES e CONT.SE
- Análise de variação percentual: (S48-S47)/S47
- Visualização de dados: gráficos para facilitar a interpretação dos resultados.

## Observação sobre os dados

Este projeto foi desenvolvido para fins de estudo, utilizando uma base de dados fictícia gerada com auxílio do ChatGPT. O objetivo foi praticar funções do Excel, analisar indicadores de vendas e extrair insights a partir dos resultados.
